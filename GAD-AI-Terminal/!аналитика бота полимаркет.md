# Аналитика — Polymarket Bot (services/polymarket-bot)

> Статус (19.06.2026): DRY-RUN активен, 94 рынка синхронизированы, первые сигналы обрабатываются

---

## Что это и зачем

Polymarket — крупнейший prediction market на Polygon (L2 Ethereum). Контракты: CLOB (Central Limit Order Book).
Каждый рынок — бинарный вопрос (YES/NO). При разрешении рынка: YES → $1.00, NO → $0.00.

**Наша стратегия**: AI (Claude Haiku) оценивает новости из X/GDELT → находит рынок где новость недооценена → покупает YES/NO → ждёт переоценки рынком.

## Архитектура (5 модулей)

```
services/polymarket-bot/src/
  markets.ts   — синхронизация рынков из Gamma API → PostgreSQL

  trader.ts    — открытие/закрытие позиций (CLOB API)
  monitor.ts   — polling TP/SL/TimeLimit каждые 30s
  index.ts     — оркестратор: 3 стратегии + Express API (port 4009)
```

## 3 стратегии поиска входов

### Стратегия 1 — X/Twitter Trend Signals
- Читает `x_trend_signals` (engagement ≥ 5000, за последние 90 мин)
- Передаёт theme + keywords в Claude Haiku
- Слабость: наши X-тренды — мемкоин темы (AI_AGENT, DOG, ELON) → плохо матчатся с политическими/спортивными рынками Polymarket

### Стратегия 2 — GDELT Trend Clusters
- Читает `trend_clusters.main_title` (за последние 60 мин)
- GDELT содержит реальные новости: Trump, G7, Elon, геополитика
- **Лучший матч** с Polymarket рынками (политика, спорт, крипто)
- Колонка `main_title` (не `cluster_label`, не `summary` — в summary есть HTML)

### Стратегия 3 — Volume Spike Detection
- Каждые 30 мин: сравнивает live-цены Gamma API с кешем в БД
- Если объём вырос ≥50% а цена не изменилась (<3%) → информационная асимметрия
- Claude анализирует аномалию → принимает решение о сделке

## AI Scoring — 2-шаговый процесс

```
Шаг 1: matchNewsToMarket()
  Вход:  newsText (≤400 chars) + список 60 активных рынков
  Модель: claude-haiku-4-5-20251001
  Выход: { market_id, affected_outcome (YES/NO), relevance 0-100 }
  Пропуск если: relevance < 50

Шаг 2: scorePosition()
  Вход:  market + outcome + newsContext
  Формула: EV = (AI_prob_YES × $1) − current_price
  Модель: claude-haiku-4-5-20251001
  Выход: { ai_prob_yes, ev, confidence (HIGH/MEDIUM/LOW), reasoning }
  Пропуск если: EV < 0.12 или confidence = LOW
```

## DRY-RUN → LIVE переключение

**Условие:** WR ≥ 65% на 30+ dry-run сделках

```bash
# В VPS .env:
POLYMARKET_DRY_RUN=false
POLYMARKET_PRIVATE_KEY=<Polygon wallet private key>
POLYMARKET_API_KEY=<из polymarket.com API settings>
POLYMARKET_API_SECRET=<из polymarket.com API settings>
POLYMARKET_API_PASSPHRASE=<из polymarket.com API settings>
```

### Как получить LIVE учётные данные

**Шаг 1 — Polygon кошелёк:**
1. Открыть MetaMask → создать новый аккаунт ИЛИ использовать существующий
2. Account Details → "Export Private Key" → ввести пароль → скопировать приватный ключ
3. Этот ключ = `POLYMARKET_PRIVATE_KEY`
4. Пополнить кошелёк USDC на сети Polygon (минимум $100 для старта)
   - Купить USDC на Binance → вывести на Polygon сеть → ваш адрес MetaMask

**Шаг 2 — CLOB API ключи:**
1. Перейти на https://polymarket.com
2. Подключить MetaMask (тот же кошелёк что в шаге 1)
3. Подписать сообщение для авторизации (sign message — это бесплатно, не транзакция)
4. Открыть Profile → Settings → API Keys (или Data & API)
5. Нажать "Create API Key"
6. Сохранить: **API Key**, **Secret**, **Passphrase** — все три нужны
7. `POLYMARKET_API_KEY=<Key>`
8. `POLYMARKET_API_SECRET=<Secret>`
9. `POLYMARKET_API_PASSPHRASE=<Passphrase>`

**Шаг 3 — Добавить в VPS .env:**
```bash
POLYMARKET_ENABLED=true
POLYMARKET_DRY_RUN=false           # включить после 30+ dry-run с WR≥65%
POLYMARKET_PRIVATE_KEY=0x...
POLYMARKET_API_KEY=...
POLYMARKET_API_SECRET=...
POLYMARKET_API_PASSPHRASE=...
POLYMARKET_POSITION_SIZE_USD=10    # размер одной позиции в USDC
POLYMARKET_MAX_OPEN=3
POLYMARKET_MIN_VOLUME=50000        # рынки с объёмом ≥$50k
```

## Известные ограничения

1. **X тренды** — наши мемкоин темы (AI_AGENT/DOG) плохо матчатся с Polymarket (политика/крипто/спорт)
2. **Claude Haiku cost** — каждый сигнал = 2 API вызова. Для объёма нужен ANTHROPIC_API_KEY с достаточным лимитом
3. **CLOB ликвидность** — малые рынки могут иметь высокий спред. Минимальный объём $50k снижает этот риск
4. **Polygon сеть** — нужен MATIC для газа (обычно $0.001 на транзакцию)
