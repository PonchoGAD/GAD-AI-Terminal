### КОРНЕВАЯ ПРИЧИНА НУЛЕВЫХ СИГНАЛОВ (новое понимание):

**Проблема НЕ в ширине окна pc1h.** Проблема в источниках токенов.

```
mom=0 означает: 0 токенов достигли проверки momentum (pc1h, pc5m)
             потому что ВСЕ токены отфильтрованы раньше
```

**Фильтр `liq=60`** — 60 токенов отклонено. Включает:
- Токены с liq > $120k (крупняк: STRAX $69M, SEI $1.5B, RENDER $2.3B)
- Токены с liq в нужном диапазоне, но с низким vol/liq ratio (SATX: vol/liq = 208/24896 = 0.84% << 10%)
- `✗liq` покрывает: мин.лик, макс.лик, И vol/liq ratio

**Фильтр `age=16`** — 16 токенов старше 6 часов

**Итог: 0 токенов проходят в momentum stage**

### Реальная проблема: Source 6 (GeckoTerminal) мертв

DexScreener возвращает ТОЛЬКО крупные/буст-токены, не свежие:
```
DexScreener token-profiles:  5 Raydium pairs from 26 new tokens
DexScreener boosts:           5 Raydium pairs from 20 boosted tokens
DexScreener top-boosts:       7 pairs
DexScreener search pumpswap:  1 pair
GeckoTerminal new_pools:      0 (429 ERR — VPS IP banned)
```

GeckoTerminal `/networks/solana/new_pools` = единственный источник свежих pump.fun→Raydium листингов.
Без него: только буст-токены и профили → все старые и большие → age-фильтр их убивает.

## ШАГ 4 — BONDING-SMART PROXY (документация)

### Текущий статус:
- `BONDING_SMART_ENABLED=false` (отключен в .env)
- PumpPortal WebSocket → 403 с VPS IP
- grad-scan WebSocket → 403 с VPS IP (каждые 60с повтор)
- Proxy support **уже закодирован** в `bonding-smart.ts`:
  ```typescript
  function buildProxyAgent() {
    const url = process.env.RESIDENTIAL_PROXY_URL; // socks5://user:pass@host:port
    if (!url) return undefined;
    return new SocksProxyAgent(url);
  }
  ```

### Для активации bonding-smart с proxy:

**1. Купить residential proxy:**

| Провайдер | Тип | Цена | Поддержка SOCKS5 |
|---|---|---|---|
| PacketStream | Residential | ~$0.10/GB (~$15/мес) | ✅ |
| BrightData | Residential | ~$8.40/GB (~$50/мес) | ✅ |
| Oxylabs | Residential | ~$15/GB | ✅ |
| IPRoyal | Residential | ~$7/GB (~$30/мес) | ✅ |

**2. Добавить в VPS .env:**
```bash
RESIDENTIAL_PROXY_URL=socks5://username:password@proxy-host:port
BONDING_SMART_ENABLED=true
BONDING_SMART_REQUIRE_SOCIAL=false
```

**3. Restart autobuy:**
```bash
docker compose restart autobuy
```

**4. Проверить лог:**
```
[bonding-smart] 🔌 Proxy enabled: socks5://...
[bonding-smart] WebSocket connected to PumpPortal
```

### Риски без proxy:
- bonding-smart получает 403 → WS соединение разрывается → reconnect каждые 60с
- grad-scan WebSocket тоже 403 → только для pre-graduation exit guard (не критично — GRAD_HUNTER_ENABLED=false)
