## Что это

Prediction market trading bot на базе Polymarket.com — торгуем исходами событий (политика, крипто, спорт, макро).

**Ключевое отличие от crypto-трейдинга:** цена контракта = вероятность события (0.0–1.0). Если "Bitcoin above $100k by Dec 2026" торгуется по $0.30 (30%), а мы думаем реальная вероятность 50% → EV = +0.20 = 20%.

---

## Архитектура

```
services/polymarket-bot/src/
  index.ts           — HTTP сервер + scheduler (каждые 15 мин)
  scorer.ts          — сигнальный движок: FAST PATH (keyword) → pre-filter → SLOW PATH (LLM)
  keyword-matcher.ts — ZERO COST матчер (NLP без API) + preFilterTrend()
  markets.ts         — Gamma API: синхронизация 94 активных рынков (с liquidityUsd)
  monitor.ts         — мониторинг открытых позиций (TP/SL/trail, каждые 30с)
  rss-sync.ts        — RSS источники: CryptoPanic + других
  trader.ts          — CLOB API исполнение (LIVE mode, сейчас выключен)
```

**Стратегии:**
1. **X Trends** — X тренды → матч с рынком (слабо матчит: крипто-тренды ≠ политические рынки)
2. **GDELT clusters** — новостные кластеры → матч с рынком (лучший результат)
3. **Volume Spikes** — рынки с аномально высоким объёмом за 1ч (>15% от 24ч объёма)

## Многоуровневый FAST PATH (29.06.2026)

### Полный поток обработки сигнала

```
Входящий сигнал (X Trend / GDELT / Volume Spike)
    ↓
[1] preFilterTrend() — 0ms, без API
    Если тренд содержит crypto/AI/DeFi ключевые слова → SKIP (не тратить LLM лимиты)
    Список: 'token', 'solana', 'pump.fun', 'ai_agent', 'llm', 'memecoin', 'defi', 'nft'...
    ↓ (прошёл — тренд не крипто-специфичный)
[2] Liquidity gate — фильтр рынков
    liquidityUsd < $5000 → пропустить рынок (слипидж при позиции любого размера)
    Fallback: если liquidity=0 → использовать 1% от volumeUsd как нижнюю оценку
    ↓ (остались tradeable рынки)
[3] FAST PATH: matchNewsToMarketKeyword() — <1ms, без API
    Named entities + word overlap + number proximity + sentiment
    Если entryPrice < 0.05 OR > 0.95 → SKIP (мёртвый рынок, нет смысла)
    Если hasSentiment (bull+bear >= 1) AND relevance ≥ 40 → MEDIUM confidence
    aiProb = capped at 0.95 (нельзя > 1.0)
    EV = aiProb - entryPrice
    Если EV ≥ 0.12 AND confidence ≠ LOW → SIGNAL SAVED → SKIP LLM
    ↓ (keyword не нашёл или LOW confidence)
[4] preFilterTrend() CHECK — второй шанс избежать LLM
    crypto/AI тренды → STOP (не звонить в LLM зря)
    ↓
[5] SLOW PATH: LLM matching (Gemini → Groq → DeepSeek → Claude)
    matchNewsToMarket() + scorePosition() + finalTradeValidation()
    Если всё одобрено → SIGNAL SAVED
```

## FREE MODE — Бесплатный Анализ

### Проблема с LLM

Prediction market odds движутся **в течение секунд** после события. LLM анализ занимает 2-5 секунд + API latency.

**Текущий статус LLM (29.06.2026):**
- Gemini: 429 (rate limit)
- Groq: 429 (rate limit)
- DeepSeek: 402 (insufficient balance)
- Claude: ошибка конфигурации

→ Все сигналы идут через FAST PATH (keyword matcher). LLM вызывается, но возвращает no-match.

### Keyword Matcher — алгоритм

```typescript
score = 0;

// 1. Word overlap (токены ≥4 букв, без стоп-слов)
score += overlapping_words * 8;

// 2. Named entity boost (40+ сущностей)
// bitcoin, trump, fed, nvidia, war, etf, election, super bowl, world cup...
score += matching_entity.length > 5 ? 30 : 20;

// 3. Number proximity (±5%)
score += 25 per matching number;

relevance = min(100, score);

// Sentiment direction
bullishWords = ['rises', 'surge', 'above', 'wins', 'approved'...] → YES для "будет ли X расти"
bearishWords = ['falls', 'drops', 'below', 'fails', 'bans'...]    → NO  для "будет ли X расти"

// EV estimate (naive Bayesian)
signalStrength = min(1, relevance / 80)
rawAiProb = entryPrice * (1 - strength * 0.4) + strength * (0.55 + strength * 0.3)
aiProb = entryPrice < 0.15 ? min(rawAiProb, entryPrice * 3) : min(rawAiProb, 0.95)
ev = aiProb - entryPrice

// Confidence
HIGH:   relevance ≥ 65 AND |bullish - bearish| ≥ 2 AND hasSentiment
MEDIUM: relevance ≥ 40 AND hasSentiment (bull+bear ≥ 1)
LOW:    иначе → ОТКЛОНЕНО
```

### Защиты от ложных сигналов (все добавлены 29.06.2026)

| Защита | Что блокирует | Код |
|---|---|---|
| Dead market filter | `entryPrice < 0.05 OR > 0.95` | keyword-matcher.ts |
| aiProb hard cap | `aiProb = min(rawAiProb, 0.95)` — нельзя > 100% | keyword-matcher.ts |
| Sentiment gate | `bull + bear = 0` → LOW confidence → отклонено | keyword-matcher.ts |
| Liquidity gate | `liquidityUsd < $5000` → пропустить рынок | scorer.ts |
| X-Trends pre-filter | crypto/AI слова → skip LLM (не Polymarket рынки) | scorer.ts |

## Почему keyword-first, а не LLM-first

Edge на prediction markets бывает только при:
1. **Speed** — мы узнали первыми (keyword <1ms > LLM 3s → keyword выигрывает)
2. **Disagreement** — наша оценка вероятности != рыночная

Keyword matcher реализует **speed advantage**. LLM как SLOW PATH — для сложных случаев. При текущем состоянии LLM (все 429/402) — только keyword path = правильная стратегия.
