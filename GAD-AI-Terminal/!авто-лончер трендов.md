| Режим | Скрипт/Сервис | Когда |

**Каждый кошелёк создаёт СВОЮ монету — без перекрёстных покупок!**

```
Тренд 1 → W1 создаёт $TOKEN_A → W1 покупает $TOKEN_A (только W1!)
Тренд 2 → W2 создаёт $TOKEN_B → W2 покупает $TOKEN_B (только W2!)

```

❌ НЕ ДЕЛАТЬ: W1 создаёт монету → W3 тоже покупает (ЗАПРЕЩЕНО!)

```

    ↓
```

## 2. Авто-лончер (trend-launcher.ts)

### Pipeline (текущий стек — 21.06.2026)

```
x_trend_signals (DB) — свежие сигналы из всех источников
    ↓ getTopTrends(3) — до 3 разных тем (dedup by theme, 24h cooldown)
    ↓ каждая тема → своему кошельку (W1→тренд1, W2→тренд2, W3→тренд3)
    ↓ Sequential с 8s stagger между кошельками (Pinata rate limit)
    ↓
[Для каждого кошелька независимо:]

cleanAndSlimTrendText(text, 250) — strip URLs/@mentions/специальные символы
    ↓
Claude claude-haiku-4-5-20251001 (max_tokens=150, compact prompt)
    → { ticker, name, description, imagePrompt }
    (fallback: OpenAI gpt-4o-mini → template)
    ↓
Pollinations.ai → 500×500 PNG лого (БЕСПЛАТНО, timeout=45s)
    ↓
Pinata IPFS → imageCID + metaCID
    ↓
Balance check: W ≥ 0.05 SOL (rent ~0.016 + buy + gas)
    ↓
pump.fun SDK: sdk.createAndBuy(kp, mintKp, ..., BigInt(devBuyLamports), 500n)
    ↓
verifyTokensReceived() — проверка что токены пришли
    ↓
DB: coin_launches (wallet_alias, wallet_address, mint_address, ...)
    x_trend_signals UPDATE action='LAUNCHED:{mint}'
Telegram: "🚀 AUTO-LAUNCHED $TICKER [W1/W2/W3]"
```

**Кулдаун:** 4 часа между циклами (TREND_LAUNCH_COOLDOWN_H=4)
**Тема-кулдаун:** 24ч дедупликация — одна тема не запускается дважды за день (isThemeOnCooldown)
**Buy amounts:** W1=0.03 SOL, W2=0.02 SOL, W3=0.01 SOL
**Источники сигналов:**
- Nitter RSS: @elonmusk, @cz_binance, @pumpdotfun (Tier1 = 50k eng), другие (Tier2/3)
- CoinGecko trending: топ-10 монет → narrative detection
- DexScreener pump.fun: word frequency в описаниях (≥5 упоминаний)
- GDELT/trend_clusters (fallback, если все остальные пусты)

### Pinata IPFS upload

```typescript
async function pinataUploadBuffer(buf: Buffer, filename: string, mimetype: string): Promise<string> {
  const form = new FormData();
  form.append('file', buf, { filename, contentType: mimetype });
  form.append('pinataOptions', JSON.stringify({ cidVersion: 0 }));
  const res = await axios.post('https://api.pinata.cloud/pinning/pinFileToIPFS', form, {
    headers: { ...form.getHeaders(), Authorization: `Bearer ${PINATA_JWT}` },
    maxBodyLength: Infinity, timeout: 45000,
  });
  return res.data.IpfsHash;
}
```


### PumpPortal buy (для ручных скриптов)

```typescript
async function pumpBuy(conn: Connection, wallet: Keypair, mintAddr: string, amountSol: number): Promise<string> {
  const r = await axios.post('https://pumpportal.fun/api/trade-local', {
    publicKey: wallet.publicKey.toBase58(), action: 'buy', mint: mintAddr,
    amount: amountSol, denominatedInSol: 'true', slippage: 30, priorityFee: 0.003, pool: 'pump',
  }, { responseType: 'arraybuffer', timeout: 25000 });

  const bytes = new Uint8Array(r.data as ArrayBuffer);
  const tx = VersionedTransaction.deserialize(bytes);  // ВСЕГДА VersionedTransaction, без fallback!
  tx.sign([wallet]);
  const sig = await conn.sendTransaction(tx, { skipPreflight: true, maxRetries: 3 });
  await conn.confirmTransaction(sig, 'confirmed');
  return sig;
}
```

## Критические правила

```
❌ НЕ ДЕЛАТЬ:
- PumpPortal action:'create' → 400 Bad Request (не работает)
- pump.fun /api/ipfs upload → 403 от VPS
- Transaction.from() fallback после VersionedTransaction.deserialize()
- Проверять byte[0] для типа TX (byte[0] = count подписей, всегда 0x01)
- BigInt(0) в createAndBuy если нужен dev buy (SDK buy упадёт — см. ниже)
- Запускать W2/W3 для трейдинга (они только для launchTriple!)

✅ ДЕЛАТЬ:
- Pinata IPFS для upload (публично доступен)
- pumpdotfun-sdk.createAndBuy() для создания (BigInt(devBuyLamports))
- metadataUri = Pinata URI (обходит pump.fun/api/ipfs блокировку)
- VersionedTransaction.deserialize() без fallback
- skipPreflight: true при отправке TX
- cleanAndSlimTrendText() перед LLM вызовом
- isThemeOnCooldown(theme) — не запускать одну тему дважды за 24ч
```

## Ошибки и решения

| Ошибка | Причина | Решение |
|---|---|---|
| `global_volume_accumulator. AccountNotEnoughKeys` | pump.fun обновил программу Feb 2026 | SDK 1.4.2 сломан; включить dev buy напрямую `BigInt(lamports)` |
| `400 Bad Request` от PumpPortal action:'create' | create не поддерживается | pumpdotfun-sdk для создания |
| `403` при доступе к pump.fun IPFS | IP-блокировка VPS | Pinata IPFS вместо pump.fun |
| `Versioned messages must be deserialized with VersionedMessage` | Неправильный тип TX | Только `VersionedTransaction.deserialize()`, без fallback |
| ts-node нет вывода в Git Bash Windows | Известный баг | Компилировать tsc → запускать node |
| Pollinations.ai timeout | Медленная генерация | timeout: 45000ms (было 60000) |
| PumpPortal buy на свежей кривой `Custom:1=SlippageExceeded` | Кривая ещё пустая | Включить buy в createAndBuy (BigInt(lamports)), не отдельным TX |
| Тема запускается дважды за день | Нет дедупликации | `isThemeOnCooldown(theme)` — проверка x_trend_signals за 24ч |
| W2/W3 слили SOL в 0 | Трейдинг на pump.fun кошельках | BONDING_HOT_ENABLED=false, SOL_VELOCITY_ENABLED=false навсегда |
| LLM входные токены высокие | URL/упоминания в тренд-тексте | `cleanAndSlimTrendText()` — 65-80% сокращение |

## Правила и ограничения

### Что автоматически НЕ запускает:

- Engagement < 10,000 (слабый тренд, нет Tier1 сигналов)
- Последний цикл < 4ч назад (кулдаун)
- Та же тема < 24ч назад (тема-кулдаун через isThemeOnCooldown)
- Баланс W < 0.05 SOL
- TREND_AUTO_LAUNCH_ENABLED=false
- Все 3 Nitter инстанса недоступны И Twitter API 402 И CoinGecko нет сигналов

### Что проверять после каждого запуска:

1. Монета появилась на pump.fun?
2. Сколько SOL в bonding curve через 1ч?
3. Достигла ли 2x? (нет follow-on buy — только dev)
4. Вышли ли dev-токены (при pump.fun graduation)?
