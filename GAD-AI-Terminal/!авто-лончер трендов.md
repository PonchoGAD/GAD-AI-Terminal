# Авто-лончер по трендам X (Twitter)
> Автоматический запуск монет на pump.fun на основе трендовых постов в X с высоким engagement.
> Обновляется после каждого запуска. Дата создания: 18.06.2026.

---

## Как работает пайплайн

```
X (Twitter) API
    ↓ scanXTrends() — ищет посты с min_retweets:25, каждые 15 мин
    ↓ фильтр: engagement >= 10,000 AND не запускали эту тему за 4ч
    ↓
Claude claude-haiku-4-5-20251001 (ANTHROPIC_API_KEY)
    ↓ generateCoinConcept(trendText, tweetUrl)
    ↓ → { ticker, name, description, imagePrompt }
    ↓
Pollinations.ai (БЕСПЛАТНО, без ключа)
    ↓ GET https://image.pollinations.ai/prompt/{imagePrompt}
    ↓ → 500×500 PNG лого
    ↓
Pinata IPFS (PINATA_JWT уже в .env)
    ↓ pinataUploadBuffer(logoBuffer) → imageCID
    ↓ pinataUploadJson(metadata) → metaCID
    ↓
pump.fun SDK (pumpdotfun-sdk)
    ↓ sdk.createAndBuy(w1, mintKp, metadata, BigInt(0), 500n)
    ↓ → createTx, mintAddr
    ↓
Telegram уведомление в ADMIN_CHAT_ID
    ↓ "🚀 LAUNCHED $TICKER — trend: THEME"
    ↓ CA, pump.fun ссылка, тренд пост
    ↓
DB (coin_ideas): сохраняем результат запуска
```

**Кулдаун:** 4 часа между авто-запусками (ENV: TREND_LAUNCH_COOLDOWN_H=4)
**Dev buy:** 0.03 SOL из W1 кошелька (ENV: TREND_LAUNCH_DEV_BUY_SOL=0.03)
**Мин. engagement:** 10,000 (ENV: TREND_MIN_ENGAGEMENT=10000)

## Правила и ограничения

### Что автоматически НЕ запускает:
- Engagement < 10,000 (слабый тренд)
- Нет нового тренда за 15 мин (нет Twitter Bearer Token)
- ANTHROPIC_API_KEY не установлен (концепт через шаблон)
- TREND_AUTO_LAUNCH_ENABLED=false (выключен)
- Последний запуск < 4ч назад (кулдаун)
- W1 баланс < 0.05 SOL (недостаточно для launch + gas)

### Что проверять после каждого запуска:
1. Монета появилась на pump.fun?
2. Сколько SOL в bonding curve через 1ч?
3. Достигла ли TP (1.5x)?
4. Вышли ли dev-токены?

## Технические детали

### Генерация концепта (Claude claude-haiku-4-5-20251001):
```
Промпт: "Based on this viral X post, create a meme coin concept.
Return JSON: { ticker, name, description, imagePrompt }"

Токены: ~200 входных + ~100 выходных = ~$0.0003 за генерацию
```

### Генерация логотипа (Pollinations.ai):
```
URL: https://image.pollinations.ai/prompt/{prompt}?width=500&height=500
Стоимость: БЕСПЛАТНО
Время: 5-15 секунд
Качество: среднее (достаточно для pump.fun)
```

### Launch параметры:
```typescript
sdk.createAndBuy(w1Keypair, mintKeypair, {
  name:         concept.name,
  symbol:       concept.ticker,
  description:  concept.description,
  twitter:      trendUrl,
  website:      'https://gadai.shop',
  file:         logoBlob,
}, BigInt(0), 500n)  // 0 initial buy via SDK, 500 slippage bps
// Dev buy отдельно через PumpPortal trade-local
```

## Известные проблемы и баги

| Проблема | Статус | Фикс |
|---|---|---|
| Twitter API v2 Basic план $100/мес — нужен для search | ⚠️ Опционально | GDELT fallback есть |
| Pollinations.ai иногда slow (>30s) | ⚠️ Ожидаемо | timeout 60s |
| pump.fun SDK: нужен funded W1 wallet | ✅ W1=0.29 SOL | ОК |
| ANTHROPIC_API_KEY не установлен | ⏳ Пользователь добавит | Шаблонный fallback |
| Дубликаты: один тренд может запуститься дважды | ✅ Фикс в коде | cooldown + DB check |
