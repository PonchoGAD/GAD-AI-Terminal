## АРХИТЕКТУРА БОТОВ

### Raydium (W1 кошелёк — EL4mS7Xg)
```
scanner (DexScreener каждые 30с)
  → фильтры: liq $12-300k, age <6h, pc5m ≥5%, pc1h 5-80%, vol/liq ≥15%
  → autobuy: 0.02 SOL, Jupiter swap
  → sell loop (setInterval 1000ms): TP/SL/Trail check
  → TP: T1=1.30x | T2=1.28x | T3=1.25x (NEUTRAL regime)
  → Stop: 8% | Trail: 12% | Early trail: 4%
```

### Bonding Smart v2 (W1 кошелёк — EL4mS7Xg)
```
PumpPortal WebSocket (real-time trades)
  → DevProfiler: >5 SOL dev buy → high conviction
  → SybilFilter: unique buyers, не wallet clusters
  → SmartMoney: tracked whale wallets buying
  → Jito submit (fresh tip для elite signals, TRAP 3)
  → vSol range: 25-80 SOL on bonding curve
  → TP: 1.5x 100% | Stop: 12% | Time limit: 90s
```

### BSC Scanner (EVM кошелёк BSC)
```
DexScreener + GeckoTerminal polling (каждые 30с)
  → фильтры: liq $15-500k, новые токены
  → PancakeSwap V2: swapExactETHForTokensSupportingFeeOnTransferTokens
  → getBscSecureGasPrice(): +1.5 Gwei sandwich protection
  → post-buy approve MaxUint256 (fire-and-forget, TRAP 1)
  → RPC 429 rotation (4 endpoints, TRAP 4)
  → 5 TP stages: 1.3/1.8/2.5/4.0/7.0x | Trail 8% | SL 10%
```

### Base Scanner (Base wallet — 0x88704Df2)
```
DexScreener + GeckoTerminal polling (каждые 30с)
  → calculateDynamicSlippage(): 3-5% на основе vol/liq ratio
  → Uniswap V3 / V2 / Aerodrome (лучшая котировка)
  → post-buy approve MaxUint256 (fire-and-forget, TRAP 1)
  → RPC 429 rotation (4 endpoints, TRAP 4)
  → 5 TP stages: 1.3/1.8/2.5/4.0/7.0x | Trail 8% | SL 10%
```

### TON Scanner (TON wallet — мнемоника)
```
GeckoTerminal + DexScreener (каждые 60с)
  → checkTonJettonSafety(): blacklist + verification gate
  → STON.fi v1 router: TON → Jetton swap
  → getNextSecureSeqno(): local counter, sync 30с (TRAP 2)
  → verifyJettonBalance(): bounce detection 15s после buy
  → 2-stage TP: 1.35x→70%, 1.80x→100% | SL 10% | TL 600s
  → BUY_TON=3.5 (gas overhead = 8.6%)
```

### Futures Service (paper mode)
```

  → MIN_MACRO_SCORE=40 (снижен с 45)
EntryStrategy (EMA21/50, RSI14, Volume Binance 15m)
  → MIN_SIGNAL_STR=50 (снижен с 55)
  → FUTURES_PAPER_CAPITAL=100 (нужен на VPS)
RiskManager (poll 3s): TP 4% / SL 2% / Trail 1.5%
Telegram: /futures /macro /signal /position /capital
```

| # | Ловушка | Где | Решение | Файл |
|---|---|---|---|---|
