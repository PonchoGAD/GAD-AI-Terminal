## ЧАСТЬ 1: Bonding Smart (pump.fun бот)

### Архитектура источников данных (все БЕСПЛАТНО)

```
PumpPortal WS (free)
  └── create events → mint, devBuy, metadata URI

Helius WS (один shared WebSocket):
  ├── accountSubscribe → bonding curve PDA → real-time vSol
  │   └── vSol delta → synthetic trade events в state.events
  │       delta > 0 → BUY event (solAmount = |delta|)  ← velocity, dump guard
  │       delta < 0 → SELL event
  └── logsSubscribe → per-token logs
      └── parsePumpAnchorEvent('Program data: <base64>') — v9
          ├── Декодирует Anchor TradeEvent: buyer address + SOL amount + vSolReserves
          ├── 0 RPC-вызовов, 100% покрытие трейдов, реальный кошелёк покупателя
          ├── smartMoneySet.has(buyer) → state.smConfirmations++
          └── Fallback: getParsedTransaction debounced 1/s (если Anchor decode не сработал)

PostgreSQL smart_money_wallets (Migration 024) → wallet_address column
  └── In-memory Set → O(1) lookup, 0 внешних API
```

**v10 архитектура (30.06.2026):**
- **Auto SM Collector**: когда DRY BUY достигает TP1 (+25%), функция `collectWinnersAsSmartMoney()` автоматически собирает всех ранних покупателей (первые 5 мин после нашей покупки) и вставляет их в `smart_money_wallets` с `source='bonding_smart_tp1'`. Каждая победа = новые SM адреса. После 30 побед будет 30-150 верифицированных кошельков вместо стартовых 10.
- **Shyft RPC Fallback**: `parseTransactionDebounced()` теперь пробует Helius первым, если ошибка/таймаут → пробует `https://rpc.shyft.to?api_key=SHYFT_RPC_KEY`. Ключ: `9NS5zPHh7tEGliuy` добавлен в VPS `.env`.
- **Архитектура SM кошельков**: бот работает НЕЗАВИСИМО от SM кошельков (`REQUIRE_SM=false`). SM — это дополнительный сигнал. Бот сканирует ВСЕ новые токены pump.fun, SM просто инкрементирует `smConfirmations`. 10 стартовых адресов → растёт автоматически.

**v9 изменения (30.06.2026):**
- **Anchor TradeEvent decoder**: pump.fun эмитит события как `Program data: <base64>` в logsNotification. Структура: discriminator(8) + mint(32) + solAmount(u64) + tokenAmount(u64) + isBuy(bool) + user(32) + ts(i64) + vSolReserves(u64) + vTokenReserves(u64) = 113 байт. Декодируется без внешних библиотек через Buffer.
- **CRITICAL BUG FIXED**: `SELECT address FROM smart_money_wallets` → `SELECT wallet_address AS address` — из-за этого бага Smart Money Set был ВСЕГДА ПУСТЫМ (с момента создания таблицы).
- **Breakeven Stop**: если цена поднялась до +10% (peakPrice ≥ entry×1.10) и вернулась к entry → экстренная продажа вместо ожидания -8% стопа.
- **Dynamic Jito**: обычные продажи 0.0005 SOL, экстренные (dump/stop_loss/pre_grad/breakeven) → 0.0012 SOL.

## ЧАСТЬ 2: logsSubscribe + Anchor decoder архитектура (v9)

### Как работает

```
Token passes shouldBuy filters
  → subscribeTokenLogs(mint) on EXISTING Helius WS
  → logsNotification messages arrive
  → Filter: log must mention PUMP_PROGRAM_ID

  ── PRIMARY PATH (v9): Anchor TradeEvent decoder ──────────────────
  → Scan logs[] for "Program data: <base64>" line
  → parsePumpAnchorEvent(logLine):
      Buffer.from(base64) → skip 8-byte discriminator
      mint(32) + solAmount(u64) + skip tokenAmount(u64) + isBuy(bool)
      + user(32) + skip timestamp(i64) + vSolReserves(u64)
      = real buyer address + exact SOL amount + updated vSol
  → smartMoneySet.has(buyer) → state.smConfirmations++
  → state.vSol = ev.vSolReserves (more accurate than accountSubscribe lag)
  → state.events.push({ts, solAmount, buyer, isBuy, isSmart})
  → 100% coverage, 0 RPC calls, real-time

  ── FALLBACK PATH: debounced getParsedTransaction ─────────────────
  → Only if Anchor decode failed (unknown event discriminator)
  → getParsedTransaction(sig) debounced 1/s → ~60 calls/min per token
  → Extract buyer from accountKeys[0] and SOL from balance diff
```

### Лимиты Helius free tier (v9)

- logsSubscribe: ок для 1-2 токенов одновременно
- Anchor decoder: **0 RPC calls** — основной путь не нагружает лимиты вообще
- getParsedTransaction: fallback только при нераспознанных событиях (редко)
- accountSubscribe: параллельно даёт vSol delta (velocity/dump detection)
