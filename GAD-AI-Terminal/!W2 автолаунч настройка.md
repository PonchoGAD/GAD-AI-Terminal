## Как работает авто-лаунч (после всех фиксов, 28.06.2026)

### Цикл — каждые 12 часов

```
[auto-launch] Starting first cycle (W2 single-wallet, 12h interval)...
    ↓
1. Проверяем дневной лимит (DAILY_LAUNCH_LIMIT=2 в .env, default=2)
    ↓
2. Проверяем баланс W2
   • < 0.025 SOL → пропуск + предупреждение "Top up wallet to resume"
   • ≥ 0.025 SOL → продолжаем
    ↓
3. Получаем СВЕЖИЙ тренд прямо сейчас (3 источника по приоритету):
   • x_trend_signals (за последние 30 мин, engagement ≥ 10000 = Tier1 вирус)
   • trend_clusters / GDELT (за последние 2 часа, score ≥ 65)
   • CoinGecko trending (прямой API-запрос — всегда есть данные)
    ↓
4. Генерируем идею монеты через Claude Haiku (claude-haiku-4-5-20251001)
   • Если Anthropic недоступен → fallback-шаблон из ключевых слов
    ↓
5. Генерируем логотип через Pollinations.ai (бесплатно, no API key)
    ↓
6. Загружаем image + metadata в Pinata IPFS
    ↓
7. Создаём токен через createSingleToken(W2, ...) — pump.fun SDK
   • devBuySol = 0.003 (если W2 ≥ 0.035 SOL) → маленькая позиция для последующей продажи
   • devBuySol = 0     (если W2 < 0.035 SOL) → только создание, нет позиции
    ↓
8. Логируем в coin_launches (wallet_alias='W2')
```

### Пример успешного цикла в логах

```

[auto-launch] Trend [coingecko/CRYPTO]: Bitcoin (BTC) is the #1 trending crypto globally

```

## Обслуживание запущенных монет (MAINT_TIERS)

Проверяется каждые **60 минут** через `runLaunchedCoinMaintenance()`.

| Тир | Возраст монеты | Мин. holders | Действие |
|---|---|---|---|
| Tier 1 | 12-16 часов | 2 | Если < 2 держателей → продать dev позицию |
| Tier 2 | 20-30 часов | 3 | Финальная уборка стагнирующих монет |

**Логика:** Если через 12 часов только один держатель (= только мы), значит никто не купил. Продаём позицию и фиксируем небольшой убыток (fees) вместо того, чтобы держать мёртвый токен.

**Только монеты с dev buy:** Обслуживание срабатывает только если `dev_buy_sol > 0` (нам есть что продавать).

### Пример в логах

```
[launcher-maint] Tier 12-16h: checking 1 tokens (min holders=2)
[launcher-maint] BTCC (CFmHWpmQ...) — W2: 1 holders @ 12-16h
[launcher-maint] ⚠️ BTCC W2: 1 holders < 2 at 12h — selling dev position
[launcher-maint] ✅ BTCC W2 sold — TX: <tx_sig>
```

## Источники трендов

### Уровни вирусности (по убыванию)

| Источник | Порог | Данные |
|---|---|---|
| x_trend_signals (Nitter Tier1) | engagement ≥ 10,000 | Посты elonmusk, vitalikbuterin и др. Tier1 аккаунтов |
| trend_clusters (GDELT) | final_score ≥ 65 | Глобальные новостные кластеры (повышен с 55 → 65) |
| CoinGecko trending | Топ-1 из trending | Самая популярная крипта прямо сейчас — **всегда доступен** |

**Важно:** Источники опрашиваются прямо перед запуском (не из кеша), чтобы идея была актуальной.

### Проблема с GDELT (28.06.2026)

Текущий `Top score: 42.9` у trend-engine — ниже порога 65. Это нормально для "медленных" новостных дней. В такие дни автолаунч переключается на **CoinGecko trending** как основной источник (всегда возвращает данные).

```bash

# Лимит запусков в день

# Claude для генерации идей (настроен)

# Pinata для IPFS (настроен)
PINATA_JWT=<jwt>
PINATA_GATEWAY=https://gateway.pinata.cloud/ipfs/
```
