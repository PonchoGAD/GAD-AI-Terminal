## Анализ: Почему нет трейдов (29.06.2026)

### Что сканер находит

| Источник | Проблема |
|---|---|
| GeckoTerminal `new_pools` | Возвращает OLD токены (FISH 21548h, @BTC25 20169h) |
| GeckoTerminal `trending_pools` | Только что добавлен (29.06). Возвращает 20 пулов, но большинство: либо слишком высокая liq ($300k+), либо 0% pc1h |
| DexScreener поиск (ton meme/dog/cat) | Возвращает старые установленные токены TON экосистемы |

### Типичный цикл (59 токенов найдено)

```
✗ KOTÉ       pc1h:-0.4%<3%     — отрицательный momentum
✗ UKWN4rlR   liq:1340<3000     — слишком мало ликвидности ($1.3k)
✗ UTYA       liq:681919>300000 — слишком много ($681k)
✗ EGOR       age:844h>720h     — слишком старый (35 дней)
✗ GM         pc1h:0.0%<3%      — нет движения
✗ MGGA       pc1h:0.0%<3%      — нет движения
cycle: found:59 filtered:33 bought:0 skip(seen:26)
```

### Ключевая проблема

TON memecoin экосистема ПРИНЦИПИАЛЬНО ДРУГАЯ от Solana:
1. **Нет эквивалента pump.fun** — нет единой фабрики мемкоинов с bonding curve
2. **Токены стартуют с низкой ликвидностью** ($500-$2000) — ниже нашего min $3000
3. **Trending токены** — слишком большие ($300k+) или старые (>30 дней)
4. **0% momentum** — большинство TON токенов торгуются без ценового движения
5. **Мало новых запусков** — особенно в FEAR рынке (F&G=12)

## Текущие Настройки (VPS .env — 29.06.2026)

```bash
TON_AUTO_BUY=false           # DRY-RUN — реальных покупок нет

# Ликвидность
TON_MIN_LIQUIDITY_USD=3000   # ↓ с 8000 → 3000 (29.06) — но всё равно нет кандидатов
TON_MAX_LIQUIDITY_USD=300000 # ↑ с 150000 → 300000 (29.06)

# Возраст
TON_MAX_AGE_SEC=2592000      # 30 дней (720h) — старые OK

# Momentum
TON_MIN_PC1H=3               # 3% — большинство токенов имеют 0%
TON_MIN_BUYS_H1=2            # добавлено 29.06

# Покупка
TON_BUY_AMOUNT=3.5           # 3.5 TON (~$14) — ВНИМАНИЕ: высокие gas fees на TON!
```

### Проблема с gas fees TON

```
STON.fi swap: 0.12-0.18 TON gas
Round-trip (buy + sell): ~0.30-0.40 TON
Gas как % от позиции: 0.35 / 3.5 = 10%

Это значит: чтобы выйти в прибыль, токен должен вырасти > 10% только на покрытие газа.
Сравнение: Solana swap = ~$0.01 gas, Raydium 0.02 SOL (~$3) позиция = 0.3% на gas.
```

## Что нужно для активации TON

### Вариант 1: Ждать лучших рыночных условий
- FEAR рынок (F&G=12) → мало новых запусков везде
- TON специфика: ждать появления новых проектов с liq $3k-$50k

### Вариант 2: Изменить стратегию discovery
Текущие DexScreener + GeckoTerminal не дают свежих токенов TON.
Нужны:
1. **DeDust API** — нативная DEX для TON (swap.coffee)
2. **TONCO DEX** — сравнительно новая DEX на TON
3. **GeckoTerminal `/networks/ton/new_pools?sort=created`** — уже используется, но даёт старые токены

### Вариант 3: Понизить min_liq до $500-$1000
Свежие TON токены стартуют с $500-$2000 ликвидности.
НО: это очень рискованно — при $500 ликвидности наша покупка 3.5 TON ($14) = 2.8% pool = huge slippage.

### Рекомендация: Оставить ОТКЛЮЧЁННЫМ до:
- [ ] F&G > 30 (нормальный рынок)
- [ ] Появление нового discovery source с реально свежими TON токенами ($3k+ liq)
- [ ] Снижение TON_BUY_AMOUNT до 1.0-1.5 TON (уменьшить gas overhead)
- [ ] Тестирование в shadow mode минимум 50 трейдов

### Архитектура

```
services/ton-scanner/          — сервис на порту 4007
  index.ts                     — запуск, HTTP сервер
  scanner.ts                   — основной сканер, фильтры, покупки
  monitor.ts                   — мониторинг позиций, TP/SL/trail

libs/ton/src/
  discovery.ts                 — discoverTonTokens() → GeckoTerminal + DexScreener
                                  + trending_pools (добавлено 29.06)
  trader.ts                    — buyJetton(), sellJetton() через STON.fi v1
  safety.ts                    — checkJettonSafety() → TonAPI
  safety-validator.ts          — checkTonHolderConcentration()
  smart-money.ts               — checkTonSmartMoney()
  client.ts                    — TonClient, WalletContractV4, getTonBalance()
```

### TP Стратегия (monitor.ts)

| Stage | Уровень | Продажа |
|---|---|---|
| TP1 | +35% (1.35x) | 70% позиции |
| TP2 | +80% (1.80x) | 100% (закрытие) |
| Trail Stop | 10% от ATH | Полное закрытие |
| Stop Loss | -10% | Полное закрытие |
| Time Limit | 10 мин (600s) | Если < 1.05x |

### Env для активации (когда будет готово)

```bash
# 1. Добавить TON API ключ (для safety checks):
TON_API_KEY=<toncenter key>   # https://toncenter.com/

# 2. Включить покупки:
TON_AUTO_BUY=true

# 3. Уменьшить позицию (gas overhead):
TON_BUY_AMOUNT=1.5            # 1.5 TON вместо 3.5

# 4. Подождать 50+ shadow трейдов с WR ≥ 40%
```

## Критические Правила

1. **НЕ ВКЛЮЧАТЬ** `TON_AUTO_BUY=true` без shadow данных (нужно 50+ трейдов)
2. **Gas fees**: 10% overhead при 3.5 TON позиции — снизить до 1.0-1.5 TON перед активацией
3. **TON_API_KEY** нужен для safety check держателей токенов (без него все токены проходят как safe)
4. **Discovery проблема**: DexScreener + GeckoTerminal для TON дают OLD токены — нужны новые sources
