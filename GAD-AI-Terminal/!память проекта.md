## Что это за проект

**GAD AI Terminal** — Solana/Base/BSC/TON мемкоин платформа:
- **Автоматическая торговля:** находит токены, покупает, продаёт по TP/SL
- **Аналитика:** скоры, скринеры, whale-трекер, социальные сигналы
- **Запуск монет:** авто-лончер по трендам X, ручной запуск
- **Telegram-бот:** @gadai_sol_bot — весь доступ для пользователей
- **Лендинг:** gadai.shop (Vercel) — подписки, оплата SOL

**Деплой:** VPS Hetzner `root@65.21.159.255`, ключ `~/.ssh/gad_deploy`
**Git:** `git push gad main` → github.com/PonchoGAD/GAD-AI-Terminal → VPS тянет оттуда
**Лендинг:** `git push gadai main` → github.com/PonchoGAD/gadai.git → Vercel
