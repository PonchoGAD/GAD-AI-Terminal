# Аналитика — TON Network Scanner (services/ton-scanner)

> Статус (17.06.2026): DRY-RUN (TON_AUTO_BUY=false), ждёт TON_WALLET_MNEMONIC для активации

---

## Что это

TON Scanner — автоторговля на TON Network через STON.fi DEX (покупка/продажа Jetton токенов).
Аналог Raydium Scanner для Solana, но для экосистемы Telegram/TON.

---

## Архитектура (7 файлов)

```
services/ton-scanner/src/
  index.ts     — Express API (port 4007), scheduler, команды
  scanner.ts   — discovery токенов каждые 60s
  monitor.ts   — мониторинг позиций (poll 10s), TP/SL
  
libs/ton/src/
  client.ts    — TonClient + WalletContractV4 (TON Connect)
  discovery.ts — GeckoTerminal + DexScreener поиск новых Jettons
  safety.ts    — проверка безопасности через tonapi.io
  trader.ts    — STON.fi v1 router: buy/sell Jettons
  index.ts     — экспорт всех функций
```

---

## Discovery (libs/ton/src/discovery.ts)

Два источника параллельно:
1. **GeckoTerminal TON pools** — новые пулы на STON.fi за последние 24ч
2. **DexScreener TON** — `dexId = 'stonfi'`

Фильтры:
- Ликвидность ≥ $10k
- Объём 24ч ≥ $5k
- Возраст: недавно созданные
- Исключить: stablecoins, TON/wTON/USDT

---

## Safety Check (libs/ton/src/safety.ts)

tonapi.io API:
- Проверяет metadata Jetton контракта
- Флаги: is_scam, honeypot checks
- Holder distribution
- Mint authority (можно ли создавать новые токены)
- Минимальный safe_score > 60

---

## Trading (libs/ton/src/trader.ts)

**STON.fi v1 Router** (`EQB3ncyBUTjZUA5EnFKR5_EnOMI9V1tTEAAPaiU_suX_e8gA`):
- `buy`: TON → Jetton через STON.fi swap
- `sell`: Jetton → TON через STON.fi swap
- Использует `@ston-fi/sdk v2.2` для построения транзакций
- Wallet: `WalletContractV4` из `@ton/ton`

## Стратегия торговли

### Entry
```
TON_AUTO_BUY_AMOUNT = 0.5 TON (default)
MAX_TON_POSITIONS   = 5
```

### 5-ступенчатые TP
| Уровень | Множитель | Продажа |
|---|---|---|
| TP1 | 1.2x | 20% |
| TP2 | 1.5x | 25% |
| TP3 | 2.0x | 25% |
| TP4 | 3.0x | 25% |
| TP5 | 5.0x | 25% (остаток) |

### Защитные уровни
- **Trail stop**: 10% от ATH (скользящий стоп)
- **Stop loss**: -8% от входа
- **Time limit**: 10 минут (мемкоины TON очень волатильны)

## Как активировать LIVE режим

```bash
# 1. Получить 24-слово мнемонику TON кошелька
#    (создать в Tonkeeper / TonSafe / TrustWallet → Settings → Backup)

# 2. Получить tonapi.io API ключ
#    Зарегистрироваться на https://tonapi.io → API Keys → Create

# 3. Добавить в VPS .env:
TON_WALLET_MNEMONIC=word1 word2 ... word24
TON_API_KEY=<tonapi.io key>
TON_AUTO_BUY=true
TON_AUTO_BUY_AMOUNT=0.5          # размер позиции в TON
MAX_TON_POSITIONS=5

# 4. Перезапустить контейнер:
docker restart gad-ai-ton-scanner
```

## Особенности TON vs Solana

| Аспект | Solana | TON |
|---|---|---|
| DEX | Jupiter / PumpPortal | STON.fi |
| Token стандарт | SPL Token | Jetton (TEP-74) |
| Время блока | ~400ms | ~5s |
| Декомпиляция TX | VersionedTransaction | WalletContractV4.createTransfer |
| Gas | SOL (lamports) | TON (nanotons) |
| Адреса | Base58 | user-friendly (EQ...) или raw |
